Sample Bug Report Structure

Summary: [Patient Module] Missing age boundary check when scheduling immunization Severity: Medium Environment: Chrome v128 / Windows 11 / Staging Build
Steps to Reproduce: 1. Log in as Healthcare Worker. 2. Navigate to "Immunization Schedule" -> "Add Patient". 3. Enter patient Date of Birth indicating an age of 5 years (60 months). 4. Click "Generate Schedule". Expected Result: System should prevent submission and display a validation error stating the valid age limit (0-24 months). Actual Result: System accepts the entry and generates a schedule for an ineligible age group.
